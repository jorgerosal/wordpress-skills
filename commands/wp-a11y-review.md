Use and follow the **wp-accessibility-review** skill to perform a comprehensive WordPress accessibility review.

**Target**: $ARGUMENTS (if empty, use current working directory)

Execute the full Code Review Workflow from the skill, load reference files as needed for deeper analysis, and format output using the skill's Output Format section with severity levels (Critical/Warning/Info). If theme markup issues dominate, suggest running `/wp-theme-review`. If block output or editor UI issues dominate, suggest running `/wp-block-review`.
